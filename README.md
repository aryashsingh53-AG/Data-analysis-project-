# 📊 HR Attrition Analytics — End-to-End Data Analysis & Dashboard

An end-to-end analytics project that answers four business questions for an HR team:

1. **How bad is attrition?** (rate, headcount lost, estimated replacement cost)
2. **Who is leaving?** (department, tenure, age, income, role)
3. **Why?** (chi-square / t-test hypothesis testing + model feature importance)
4. **Who is at risk next?** (ML risk scoring + ranked watch-list)

> **Data note:** The dataset is synthetic (generated by `src/generate_data.py`) using a schema modelled on the
> IBM HR Analytics dataset, with realistic drivers baked in. To use real data, drop a CSV with the same
> columns into `data/hr_attrition.csv`.

## Tech stack
Python · pandas · SciPy · scikit-learn · Plotly · Streamlit

## Project structure
```
├── app.py                  # Streamlit dashboard (4 tabs)
├── src/
│   ├── generate_data.py    # synthetic dataset generator
│   ├── analysis.py         # cleaning, feature engineering, statistical tests, cost model
│   └── model.py            # Logistic Regression vs Random Forest, permutation importance
├── data/hr_attrition.csv
└── requirements.txt
```

## Methodology
- **Feature engineering:** age groups, income quartiles, tenure bands, promotion lag.
- **Hypothesis testing:** chi-square for categorical drivers, Welch t-test + Cohen's d for numeric ones.
- **Modelling:** stratified 75/25 split, class-weight balancing for the imbalanced target, evaluated on
  ROC-AUC, precision, recall and F1; **permutation importance** on held-out data for explainability.
- **Business impact:** adjustable replacement-cost assumption (x annual salary) for $ impact.

## Key findings (on the included data)
- Employees working **overtime** leave at ~2x the rate of those who don't.
- Attrition is highest in the **first 2 years** and among **low-income, low-satisfaction** staff.
- Gender shows **no statistically significant** relationship with attrition.
- Best model reaches **ROC-AUC ≈ 0.80** (Logistic Regression beat Random Forest — a good reminder to always baseline).

## Run locally
```bash
git clone https://github.com/<your-username>/hr-attrition-analytics.git
cd hr-attrition-analytics
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m src.generate_data      # optional: regenerate data
python -m streamlit run app.py
```
